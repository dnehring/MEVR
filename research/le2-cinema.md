# ME2 cinema and conversation interrupts (M5)

ME2 reuses [ME1’s stereo cinema](52-cine-3d-screen.md) for in-engine conversations and cutscenes. Halcyon’s modes 5 and 6 select the screen when same-frame stereo is enabled. Halcyon’s flat panel handles pre-rendered movies and remains available for either scene type. A scene already owned by Halcyon’s first-person conversation latch keeps that presentation.

- `src/halcyon/le2/me2_xr.cpp` selects the presentation, submits each eye’s authored camera view to its own quad on the same room-fixed screen, and uses the shared cinema pacing preference. `calcview_hook.cpp` keeps headset motion out of the director’s camera. The headset still moves relative to the screen.
- `src/plugin/CineScreen.cpp`, `CinemaBackdrop`, `WorldPanels` and `TransitionFade` share screen geometry, floor and horizon, layer sizing and the fade back to gameplay with ME1. `HudPanel` puts reply choices, subtitles and other native scene UI just in front of the screen. The wrist UI keeps its own panel and mask.
- Comfort offers 3D screen and flat presentation for conversations and cutscenes, plus screen width, distance and depth. The defaults in `ASI/LE2MEVR.ini` under `[Cinematics]` are a 2.9 m-wide 16:9 screen at 3.5 m, 1% depth, and `fullRate=1`. With Halcyon’s display-locked pacing enabled, `fullRate=0` requests a frame interval of twice the display interval during cinema. The fake headset can check the requested interval. Headset performance and comfort need a physical pass.
- While ME2 is in conversation, `PadMerge::ConversationTriggers` routes the physical left and right triggers through pad 0 as LT (Paragon) and RT (Renegade). Configuration for squad orders, support grip and other gameplay trigger owners does not take effect in this mode. The mod menu and calibration still capture open-menu input and suppress held inputs until release. ME2 handles prompt timing and evaluates the story branch. The [interrupt acquisition note](le2-interrupt-acquisition.md) traces the native route and describes the required saves.

## Reproduce the cinema check

1. Build the LE2 Release host and mod. Use [the protected LE2 runner](../tools/le2-halcyon-run/README.md) to prepare, launch and load Freedom’s Progress `Save_0004`. Let `restore.ps1` return the game files, saves and SteamVR settings at the end, including on failure.
2. With `tools/console.ps1`, run `mevr instances SFXGame.BioSeqAct_StartConversation ProFre_050Shuttle`. Confirm instance 0 is `BioD_ProFre_050Shuttle`’s `SFXSeqAct_StartConversation_1`, then run `mevr activate 0 0` to start that native scene. Capture both eyes and the JSON with `tools/snapshot.ps1`. Look for `cineScreen.active`, distinct left and right eye visibility on the screen quads, the native UI layer, and the floor outside the screen. Set `[Cinematics] conversations=0` to check the flat panel. In stereo, check `fullRate` in the metadata and the pacing target in the renderer log when changing the rate.
3. Make a synthetic OpenXR recording with `py -3.12 tools/make-interrupt-recording.py triggers.mevrrec --seconds 16 --pull left:3:0.45 --pull right:6:0.45`. Play it with `tools/replay.ps1 -Path triggers.mevrrec -Inputs`. The development log prints post-filter pad 0 trigger edges. The shuttle has no interrupt prompt, so this checks the route and lack of a spurious reply. A second recording with `--seconds 19 --a 1.2` advances the scene into the following cutscene. Check the mode 6 screen and let it return to gameplay before checking the wrist Squad screen.

## Freedom’s Progress evidence (2026-11-15)

The LE1 and LE2 Release targets built successfully, and `mevr-tests` and `mevr-pad-merge` passed. The protected LE2 run `20261115-042015-m5-cinema` showed the flat conversation on one quad. After enabling 3D, each eye had its own quad and the reply wheel and subtitles were captured on a separate HUD layer. The 90 Hz pacing target changed from 11.11 ms to 22.22 ms in half-rate cinema and back to 11.11 ms at full rate. Presentation and pacing were exercised through the INI.

The pad trace shows `LT 255, RT 0`, release, then `LT 0, RT 255` and release. The same reply choices stayed on screen. Native A inputs advanced the conversation to the in-engine cutscene on the stereo screen. The scene returned to mode 0 with a 0.35 s fade, then the wrist Squad screen opened and closed. The Veetor scene lookup returned no live conversation start in this state. Logs are in the protected session’s `logs` folder, with tagged frames in `%LOCALAPPDATA%/MEVR/snapshots`.

## Timed interrupt acceptance

The available Save 4 predates Veetor’s encounter. Advance naturally to Veetor and collect a save that normal-loads before the relevant dialogue, as described in the [acquisition handoff](le2-interrupt-acquisition.md#acquisition-from-the-owners-freedoms-progress-save-4). For each polarity, confirm the correct prompt is visible on the screen, then replay a trigger inside its native time window and another outside it from matching starting state. Check the spoken branch and normal outcome save. A pad edge in the shuttle or a direct script call alone cannot establish story acceptance.
