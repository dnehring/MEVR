# 04: ME LE modding ecosystem

## General

- Fans build and maintain **Legendary Explorer (LEX)**, a GPL-3.0 toolkit with about 30 tools.
  BioWare never released official tools. [Nexus news, GitHub API]
- **Original-trilogy mods don't work on LE** and can't be ported quickly because of back-end
  changes. Most are rebuilt from scratch. [Nexus news]
- Most LE mods install through **ME3Tweaks Mod Manager**, which covers all three games.
  [GameRevolution, PC Gamer]

## Native code path: ASI plugins

- **LEBinkProxy** (ME3Tweaks): a multi-purpose proxy DLL for ME LE that can open the console,
  **load native plugins** (ASIs) and bypass the launcher. No license file detected. [ME3Tweaks
  GitHub, GitHub API]
- **ASI mods** are DLLs that get injected automatically. The forum warns they are effectively
  executables, so only run trusted ones. [ME3Tweaks forum]
- An old **ProcessEvent hook example** (original ME3, not LE) found a function by name, read its
  vtable, took **entry 70** as ProcessEvent, and detoured it. The poster said it wasn't working.
  The vtable index almost certainly differs in LE. [ME3Tweaks forum]
- **Per-game repos** `LE1-ASI-Plugins`, `LE2-ASI-Plugins`, `LE3-ASI-Plugins`: development **moved
  to `LExASIs` in Feb 2026**. LE1's repo had 2DAPrinter, KismetLogger, LE1AppearanceTest,
  LE1AutoloadEnabler, LE1ConsoleExtension, LE1DebugLogger, LE1DiscordIntegration,
  LE1FunctionLogger, LE1LEXInterop, LE1SeekFreeEnabler, LE1StreamingLevelsHUD, LinkerPrinter,
  MExperiments, PNGScreenshots, SeqActLog Enabler, UnrealscriptDebugger, plus `LE1-SDK` and
  `LE1ASITemplate`(.zip). [LE1-ASI-Plugins repo]

## LExASIs (current native-plugin repo)

- "Native mods for Mass Effect (Legendary Edition) games." CMake (`CMakeLists.txt`,
  `CMakePresets.json`). One repo for all three games. [LExASIs repo]
- **Plugins:** 2DAPrinter, AceSlammer, AutoTOC, Autoload, ConsoleExtension, **ConvoSniffer**,
  DebugLogger, DiscordIntegration, FunctionLogger, **HotReload**, KismetLogger, LEXInterop,
  LinkerPrinter, PNGScreenshots, SSRUnlocker, SeqActLogEnabler, StreamingLevelsHUD, TextureOverride.
- **Common/:** `Base`, `DefaultLogger`, `ME3TweaksLogger`, `Memory`, `Mount`, `Objects`, `Utils`
  (.cpp/.hpp), `json.hpp`.
- **External/ (submodules):** `LExSDKv2` (llamathings), `spdlog`, `simdutf`.
- **No license stated.** Read it for patterns; ask ME3Tweaks before copying code.
- Plugins of interest to us:
  - `ConvoSniffer`: detecting conversation state, for switching to the cinema screen.
  - `HotReload`: fast iteration.
  - `FunctionLogger` / `KismetLogger`: discovering which UnrealScript functions fire.
  - `LEXInterop`: live link with Legendary Explorer.

## LExSDKv2

- "Foundation for building native mods for Mass Effect Legendary Edition trilogy." Code
  auto-generated by an adapted version of TheFeckless' UE3 SDK generator
  (`d00telemental/LExSDKGenerator`), plus a partial TMap implementation by SirCxyrtyx.
  [LExSDKv2 README]
- **Deliberately unlicensed.** It's derived from information extracted from the games and earlier
  UE3 titles, which puts it in modding's legal gray area. The author would "prefer to avoid testing
  that theory". [LExSDKv2 README]
- **For us:** consume it as a git submodule, the way LExASIs does. Don't copy it into our
  MIT-licensed source. Note: compiled ASIs inevitably include SDK-derived code. That's the norm
  for every LE native mod.

## UDK interop

See [01-feasibility.md](01-feasibility.md): UDK 2015 is used for level geometry and lightmaps. It's
irrelevant to VR rendering but useful if we ever need custom meshes (holsters, a wrist HUD mount).
